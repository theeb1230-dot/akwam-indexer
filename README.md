# Theeb Engine — ذيب

محرك خلفي متعدد المصادر للبحث عن المحتوى، توحيد نتائجه، بناء مكتبة محلية، وحل خيارات تشغيل الحلقات خلف API موحّد.

> المشروع في مرحلة تطوير مبكرة. استخدم فقط المصادر والمحتوى الذي تملك تصريحًا قانونيًا للوصول إليه أو معالجته.

## المزايا الحالية

- سجل مركزي لمزودي المحتوى (Provider Registry).
- بحث متزامن في عدة مصادر.
- تجميع النتائج المتطابقة في كيان موحّد (Canonical Grouping).
- حل المسلسلات والحلقات عبر أكثر من مصدر.
- مكتبة SQLite محلية.
- استيراد وتحديث المحتوى عبر مهام خلفية.
- مسار تشغيل موحّد مع دعم HTTP Range.

## المصادر المسجلة

Akwam، ArabSeed، WeCima، Shahid4u، LodyNet، Qask، CimaLeek، وLaaroza.

تختلف قدرات البحث والفهرسة والتشغيل من مصدر إلى آخر. راجع [حالة المصادر](docs/PROVIDERS.md).

## المتطلبات

- Node.js 22 أو أحدث.
- npm.
- اتصال بالمصادر المصرح باستخدامها.

## التشغيل

```bash
npm ci
npm start
```

للتطوير مع إعادة التشغيل عند تغير الملفات:

```bash
npm run dev
```

الخادم يستمع افتراضيًا على المنفذ `3000`. لتغييره:

```bash
PORT=8080 npm start
```

## الاختبارات

```bash
npm test
```

تُشغّل الاختبارات تلقائيًا أيضًا عبر GitHub Actions عند الدفع وفتح Pull Request.

## أهم المسارات

| المسار | الوظيفة |
|---|---|
| `GET /` | حالة المحرك والمسارات |
| `GET /api/providers` | قائمة المصادر |
| `GET /api/providers/details` | قدرات المصادر |
| `GET /api/search?q=...` | البحث متعدد المصادر |
| `GET /api/resolve?q=...` | حل مسلسل موحّد |
| `GET /api/resolve/episode?q=...&season=1&episode=1` | حل حلقة |
| `GET /api/library/series` | مكتبة المسلسلات |
| `GET /api/library/stats` | إحصاءات المكتبة |
| `POST /api/import/:provider/:seriesId` | استيراد مسلسل |
| `GET /play/:provider/:watchId/:episodeId?quality=720p` | التشغيل عبر ذيب |

راجع [توثيق API](docs/API.md) للتفاصيل.

## هيكل المشروع

```text
src/
├── db/          # SQLite والجداول
├── providers/   # تكاملات المصادر
├── routes/      # مسارات HTTP
├── scraper/     # قاشط أكوام منخفض المستوى
├── services/    # البحث والحل والاستيراد والمهام
└── server.js    # نقطة تشغيل الخادم
```

بيانات `data/` تشغيلية محلية ولا تُرفع إلى Git. ينشئها التطبيق عند الحاجة.

## الاستضافة الصفرية متعددة المنصات

سياسة المشروع الحالية هي تشغيل البنية بتكلفة استضافة **0 ريال**. يتم توزيع الأدوار على خدمات مجانية بدل الاعتماد على خادم مدفوع واحد. راجع [خطة الاستضافة الصفرية](docs/ZERO_COST_HOSTING_AR.md) و[دليل النشر](docs/DEPLOYMENT.md). لا يتم إنشاء موارد مدفوعة أو ترقية تلقائية عند نفاد الحصص المجانية.
