# Cloud Run templates — reference only

هذه القوالب ليست مسار النشر الافتراضي لـTheeb Engine في المرحلة الحالية.

سياسة المشروع هي `THEEB_ZERO_COST_ONLY=true`. Cloud Run يملك Free Tier، لكنه خدمة يمكن أن تنتج تكلفة عند تجاوز الحصة، لذلك لا يُعتمد ضمن zero-cost allow-list.

القوالب محفوظة فقط كمرجع معماري واختبارات deployment السابقة. المسار التشغيلي الحالي موثق في:
- `docs/ZERO_COST_HOSTING_AR.md`
- `docs/DEPLOYMENT.md`
