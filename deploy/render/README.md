# Render Free deployment

This target is intentionally limited to Render's **free** web-service plan.

- Service: `theeb-arab-api`
- Runtime: Docker, using the final `api` stage in the repository Dockerfile.
- Public endpoint: Render's automatically managed `onrender.com` HTTPS subdomain.
- Health check: `/readyz`.
- Auto-deploy: only after linked branch checks pass.
- Instance count: exactly 1; no autoscaling.
- Production database: external PostgreSQL supplied through the secret `DATABASE_URL`.
- Production startup fails closed unless PostgreSQL, verified TLS, parity, runtime role, and zero-cost target checks all pass.
- `THEEB_API_TOKEN` is generated by Render and never committed.

The preferred persistent database is a separate free PostgreSQL provider such as Neon Free. Do not paste credentials into Git or workflow inputs.

After provisioning, prove the deployment with the repository's **External Deployment Evidence** workflow and only then run **Client Release Artifacts** against the same HTTPS URL.
