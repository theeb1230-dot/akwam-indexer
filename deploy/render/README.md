# Render Free experimental deployment

This target is intentionally limited to Render's **free** web-service plan and is an **Experimental release candidate host only**.

Render documents Free web services as suitable for testing/hobby/preview use rather than production workloads, and Free web services can spin down after inactivity. Therefore:

- Never use this target as evidence for Beta/Golden/Complete hosting readiness.
- The Node process still runs with `NODE_ENV=production` so security and PostgreSQL configuration fail closed.
- Service: `theeb-arab-api`.
- Runtime: Docker, using the final `api` stage in the repository Dockerfile.
- Public endpoint: Render's managed `onrender.com` HTTPS subdomain.
- Health check: `/readyz`.
- Auto-deploy: only after linked branch checks pass.
- Instance count: exactly 1; no autoscaling.
- Production-mode database configuration: external PostgreSQL supplied through the secret `DATABASE_URL`.
- Startup fails closed unless PostgreSQL, verified TLS, parity, runtime role, and zero-cost target checks all pass.
- `THEEB_API_TOKEN` is generated by Render and never committed. Public client routes remain controlled by the explicit public-client allowlist; privileged routes still require authentication.

The preferred persistent database is a separate free PostgreSQL provider such as Neon Free. Do not paste credentials into Git or workflow inputs.

After provisioning, prove the deployment with the repository's **External Deployment Evidence** workflow and only then run **Client Release Artifacts** against the same HTTPS URL. Successful evidence can contribute only to the Experimental readiness level while this host remains on Render Free.
